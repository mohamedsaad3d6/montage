# مونتاج — Montaj

برنامج مونتاج محلي بواجهة عربية لإدارة الحلقات، التقطيع، المراجعة، الخامات والمونتاج والتصدير.

**نسخة تسليم للاختبار داخل الشركة: 0.1.0-rc.1.** ليست إعلانًا بأن كل حلقة ستخرج تلقائيًا بلا مراجعة. حالة الخدمة والنتيجة تظهران بحسب الأدلة المتاحة؛ وجود مفتاح أو تسجيل الدخول وحده لا يثبت نجاح المونتاج.

## التشغيل على Windows

١. افتح [صفحة التنزيل](https://github.com/mohamedsaad3d6/montage/releases) وحمّل `Montaj-Setup.exe` من الإصدار `v0.1.0-rc.1`.
٢. شغّل الملف بحساب Windows العادي. أول تشغيل يجهز الأدوات والنماذج محليًا ويحتاج إنترنت ومساحة متاحة لا تقل عن ٢٠ جيجابايت، بالإضافة إلى مساحة الفيديوهات. حجم التنزيل عدة جيجابايت ويتوقف الوقت على الاتصال.
٣. يفتح البرنامج في المتصفح تلقائيًا. عنوانه المحلي: `http://127.0.0.1:8877/control/index.html`.
٤. اربط حساب ChatGPT الخاص بالشركة من زر الربط في نافذة التشغيل، ثم أضف مفاتيح الخدمات التي تستخدمها الشركة حسب [دليل الاستلام](COMPANY-START-HERE.md).
٥. ابدأ بمقطع عربي قصير. لا تعتمد حلقة للنشر قبل مراجعة النتيجة.

أعد تشغيل نفس الملف لفتح البرنامج لاحقًا؛ لا يعيد تنزيل الملفات المطابقة. لا تحتاج الشركة تثبيت Python أو Node يدويًا. البيانات محفوظة في `%LOCALAPPDATA%\Montaj\data`، والأدوات في `%LOCALAPPDATA%\Montaj\app`. لا تُضمّن أي مفاتيح حسابات أو حلقات محمد في هذه الحزمة.

## ما يشمله التسليم

- صفحات الحلقات والمدخلات والمراحل والمونتاج والمكتبة والقنوات والخدمات.
- محرك محلي للتفريغ ومحاذاة الكلمات وخطط التقطيع، مع حفظ الأصل والإصدارات.
- الموشن والعناوين العربية والخرائط ومكتبة وصفات الانتقال ومزج الصوت.
- ربط Codex للتخطيط واختيار الخامات ضمن الإمكانات الموجودة، وربط Gemini للمراجعة عند إعداد حساب الشركة والموافقة على إرسال الصوت.
- اختيار مرشحات Storyblocks تلقائيًا عند توفر الموصل على حساب الشركة. **البحث والاختيار لا يعنيان تنزيلًا مرخصًا تلقائيًا أو اعتماد اللقطة للمونتاج.**

## حدود مهمة قبل التشغيل الإنتاجي

- التسريع ببطاقة NVIDIA لم يعتمد بعد. المثبّت يستخدم مسار CPU للتوافق؛ قد يكون أبطأ في الحلقات الطويلة. وجود ٦٤ جيجابايت RAM لا يثبت سرعة التقطيع.
- فحص Windows الآلي للبناء والتشغيل لا يعادل اختبار حلقة عربية كاملة على جهاز الشركة. راجع [سجل الاختبار](VALIDATION.md).
- الخدمات الخارجية تستخدم حسابات الشركة. لا يوجد رصيد مشترك أو اشتراك جديد أو تحويل تلقائي لخطة أعلى. Magnific لا يبدأ استهلاكًا بمجرد الإعداد.
- تعطل المراجعة الخارجية لا يُسجّل كمراجعة ناجحة؛ البوابات غير المكتملة تبقى ظاهرة. بعض حالات الاستثناء تحتاج تدخلًا من المستخدم.
- **ترخيص Remotion:** الاستخدام المجاني متاح للأفراد وللشركات حتى ٣ أشخاص وفق الشروط المنشورة. على شركة أكبر مراجعة [الترخيص الرسمي](https://www.remotion.dev/docs/license/pricing) قبل استخدام محرك الموشن في الإنتاج. لم يتم شراء ترخيص أو تفعيل فوترة.
- لا تُنقل الخامات المرخصة أو شعارات القنوات الخاصة تلقائيًا إلى جهاز آخر. راجع [ملاحظات المصادر](THIRD-PARTY-NOTICES.md).

## للمطور أو الدعم

الكود داخل `source/app-local` والمحرك داخل `source/engine`. ملفات إنشاء المثبّت وفحوصه داخل `packaging`. بناء Windows متاح من Actions → Build Windows acceptance candidate → Run workflow.

هذه نسخة مستقلة من مشروع العمل؛ الإصلاحات الخاصة بويندوز لا تغير قاعدة بيانات جهاز التطوير أو حلقاته.
